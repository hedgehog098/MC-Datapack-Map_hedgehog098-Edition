## 一键配置

首次使用先双击项目根目录的 **`setup.command`**，或在该目录执行：

```sh
bash setup.command
```

它会准备兼容的 Node.js、按锁文件安装依赖、校验并下载原版资源、安装测试浏览器、执行单元测试并构建地图。首次需要联网，不需要 Python。所有配置选项集中在 `setup.command` 顶部，详见[配置表](docs/PROJECT-STRUCTURE.md#一键配置选项)。

已有项目专用 Node 时优先使用；否则使用兼容的系统 Node（≥22.18），缺失时自动下载并校验到 `.tools/node`，不修改系统 Node 或 shell 配置。重复执行会重装锁定依赖、复用有效资源并重新构建。

需要配置完成后立即进入开发页面，执行 `bash setup.command --dev`。默认执行不启动服务器，也不运行完整的浏览器回归测试。

已在 macOS 验证安装流程。自动运行环境安装支持 macOS / Linux 的 arm64、x64；Linux 可能还需安装 Playwright 提示的浏览器系统库。Windows 请使用合适的 WSL 环境；双击 `.command` 启动器适用于 macOS。

## 日常启动与更新

配置完成后，双击 **`启动地图.command`**，打开 http://127.0.0.1:4173/ 。终端保持打开，按 Control+C 停止服务。依赖、默认原版包或构建文件缺失时，启动器会调用一键配置。

修改源码后执行 `npm run build` 并刷新网页；已有构建不会由日常启动器自动更新。也可重新运行 `bash setup.command` 完成安装检查和构建。开发模式用 `npm run dev`，地址为 http://127.0.0.1:5173/ 。

如果只有项目专用 Node，手动运行 npm 前先在项目根目录执行：

```sh
export PATH="$PWD/.tools/node/bin:$PATH"
```

不同端口、`localhost` 与 `127.0.0.1` 的浏览器存储互不相通。日常使用请固定为同一浏览器、同一地址的 4173 端口。

## 功能

- 在上方结构菜单勾选结构后，展开侧栏“结构图标优先级”，逐项选择：高（所有缩放等级）、中（≥ -3）、低（≥ -1）、自动（原项目基于结构密度的规则）。地图缩放范围为 -6 至 1，越小表示看得越远。优先级只影响选中且上游算法支持的结构。
- 在地图右下角输入 X、Z，点击“确定”或按 Enter 将地图中心移到该坐标，保持当前缩放。支持正负坐标和小数，限制在 ±30,000,000 内。
- 自动保存世界版本、种子、维度、世界预设、语言、开发模式、生物群系筛选、结构选择及优先级、阴影/海平面/投影/网格/高度，以及地图中心和缩放。比较序列化后的内容，仅在变化时写入；中心在移动结束时保存，隐藏或离开页面时补存。
- 当前数据包列表存入浏览器 IndexedDB，ZIP/JAR 文件和通过文件列表导入的目录会保留；Modrinth 和内置数据包保留来源。文件夹句柄受浏览器权限限制，权限失效时需要重新选择目录。链接中的世界参数优先于已保存默认值。
- 配置保存在当前浏览器的站点存储中，清除站点数据或使用无痕模式可能使配置无法长期保留。

## 性能修改

- 修复离屏结构图标仍被 Leaflet LayerGroup 引用的问题。
- 结构任务按短时间片分批运行，移动结束事件合并处理；重新移动时取消未处理的旧结构任务。
- 瓦片数据由嵌套单元对象改为 Float64Array + Uint16Array 和生物群系字典，使用 transferable buffer 传递给主线程，避免复制每个单元对象。保留 64 位数值精度。
- 移除 worker 每秒轮询，任务到达即处理。以请求 ID 和计算代次丢弃旧瓦片结果，串行更新线程状态，卸载地图时终止线程和订阅。
- 缩小离屏瓦片保留范围，按机器逻辑核数启用 1–4 个计算线程。本机部署不发送统计请求。

高优先级会使远景同时显示更多结构，因此仍可能增加计算时间。大型自定义世界生成数据包的耗时取决于其噪声和结构复杂度。

## 加载提示与远距离路线搜索

地图顶部现在按“低 / 中 / 高 / 自动密度规则”分别说明被隐藏的结构类型，并显示类型数量。数量是结构种类数，不是假定的隐藏坐标数。结构计算未完成时显示候选计算进度，图片未完成时显示图片剩余数；计算或图片下载失败会单独提示。世界数据重载期间暂停旧任务，避免读取正在更新的注册表。

侧栏展开“远距离结构搜索 / 路线”：

1. 展开“选择结构类型”，选择任意一个或多个类型。它们合并成一个搜索集合，与地图图标的勾选和优先级无关。可以命名并保存多个分组，也可以更新或删除组。
2. 设置结果上限和半径，默认 **50 个 / 70,000 格**。任一条件达到即结束。数量允许 1–500，半径允许 1–1,000,000 格。可选的“结果最小间距”默认为 0；增大它可以筛选相距较远的地点。
3. 点击“开始搜索并规划路线”。以点击时的地图中心为固定起点，按网格环向外扫描，不会随拖动地图改变起点。显示候选检查数与找到数量，可随时停止并保留当前已找到的结果。
4. 结果为从起点出发、不返回起点的路线，使用最近邻 + 2-opt 优化 X/Z 平面直线距离。属于旅行商问题的近似解，不保证全局最优，也不考虑地形、道路、传送门或行进方式。按扫描顺序取到数量上限，不承诺选出半径内距离起点最近的所有地点。
5. 点击结果的 X/Z 按钮将地图移到该地点；“复制 X/Z 路线列表”复制带序号、结构 ID 与坐标的制表符分隔列表。
6. “最近两次搜索记忆”保留最近两次非空结果，主动停止的非空结果也计入；空结果不覆盖记忆。下一轮排除这两批中相同结构类型及 X/Z 的地点。不同分组共享去重，第三批非空结果写入时淘汰最旧一批。分组、参数和两次记忆均保存在本机浏览器；可以查看旧路线或手动清空记忆。

记忆按版本、种子、维度、世界预设、数据包来源（本地文件的名称/大小/修改时间等）区分。切换世界会取消进行中的搜索并清空当前显示，其他世界的记忆仍可见但不参与去重。同一文件夹内部内容的修改无法仅凭句柄名称识别，此时可手动清空旧记忆。

当前定位能力沿用项目的世界生成算法：矿井、下界化石、海底神殿、废弃传送门等上游暂不支持的类型在选择器中禁用；不能定位的类型不会被伪造为搜索结果。

验证：`npm test` 包含路线、扫描半径、间距、取消和两次记忆测试；`tests/browser/route-browser.mjs` 验证三次各 50 个地点的搜索去重、分组持久化、坐标定位、隐藏等级和取消；`tests/browser/map-status-browser.mjs` 验证图片状态、稀疏要塞搜索和连续切换种子。测试使用隔离浏览器，不会替换日常使用的配置。

## 界面整理

- 桌面侧栏与地图并排显示；收起侧栏时地图自动扩展。窄屏默认收起侧栏。
- 世界设置、结构优先级、路线搜索、已加入的数据包和界面设置分区展示；顶部保留数据包、群系和结构三个常用操作。
- 数据包列表默认折叠，标题显示已加载数量（包含原版包），展开状态会保存。展开后仍可查看兼容性提示、导入和移除自定义数据包。
- 移除界面中的外部推广/关于/翻译链接、翻译进度徽章、Leaflet 角落标识及独立外部统计脚本；语言和开发选项收纳至“界面设置”。项目版权与许可证文件保留。
- `tests/browser/ui-browser.mjs` 检查桌面/窄屏布局、折叠状态记忆、侧栏尺寸变化、坐标定位和路线搜索。

## 空岛结构兼容性

结构定位按结构生成点的 Y 高度检测群系，独立于地图当前显示高度。已修复 deepslate 0.25.1 将单个群系字符串解析为空集合的问题（例如 Terralith 四季空岛法师塔）；数组和 `#群系标签` 写法保持兼容。高度感知定位不等于完整模拟结构方块放置，实际世界仍需使用相同 Minecraft 版本、种子、数据包和世界生成设置核对。

本地回归验证（不附带或上传第三方数据包）：

```sh
DATAPACK_DIR='/你的数据包文件夹' npm run test:terralith
```

需先运行开发服务器，测试使用种子 `471480205331863603`、中心 `(0, 0)`、半径 70,000、上限 50。测试输出 `tests/results/terralith-results.json`，包括结构高度与 Y=64 群系对照。

## 验证与开发命令

在项目根目录执行；运行浏览器回归前先构建最新代码。

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 启动开发服务，默认 5173 端口 |
| `npm run build` | TypeScript 检查与生产构建 |
| `npm run preview` | 启动生产预览，4173 端口 |
| `npm test` | 坐标、优先级、存储、结构群系解析、路线扫描及两次记忆回归 |
| `npm run test:browser` | 自动启动独立测试服务，执行六组浏览器回归并关闭服务 |
| `npm run assets` | 校验原版 ZIP/JSON，下载缺失或损坏资源 |

浏览器回归使用独立的 5174 / 4174 端口和隔离浏览器上下文，不覆盖日常配置。默认使用项目安装的 Playwright 与 Chromium；自备工具可用 `PLAYWRIGHT_PATH`、`BROWSER_CHANNEL` 覆盖。结果与截图统一写入 Git 忽略的 `tests/results/`。

2026-10-27 整理后的验证：11 项单元测试、6 组浏览器回归以及生产构建通过。覆盖坐标定位、优先级显隐、加载提示、三轮路线搜索去重、分组、剪贴板、界面折叠、ZIP 与设置恢复。原版场景连续 8 次移动的缓存为 26–38 块瓦片，图层组图标数量与有效图标引用一致；这是特定场景的回收检查，不代表所有数据包的内存占用或速度。

原版资源由 `scripts/download-assets.mjs` 从上游部署下载；结构物品图标和 Modrinth 功能仍可能访问网络。`scripts/createVanillaZips.py` 是可选的上游高级生成工具，需要另行安装 Python 及 `scripts/requirements.txt`，常规配置不执行。

## 常见问题

- **刷新后设置不见了**：检查浏览器、主机名和端口是否一致，是否使用无痕模式或清除了站点数据。
- **改过源码但页面没变**：重新构建，再刷新生产页面。开发页面和生产页面是两个地址。
- **一键配置中断**：查看终端最后的具体错误，修复网络或权限问题后重跑；有效资源会复用。
- **双击脚本无法执行**：在终端进入项目目录后执行 `bash setup.command`；日常启动可执行 `zsh 启动地图.command`（macOS）。
- **浏览器测试端口被占用**：关闭对应测试服务，或通过 `TEST_DEV_PORT`、`TEST_PREVIEW_PORT` 指定两个不同的空闲端口。
- **安装时跳过了测试浏览器**：重新运行默认配置，或执行 `npx playwright install chromium` 后再测试。
